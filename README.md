# Zhihu & CSDN No-Login Browser Extension
浏览器，知乎和CSDN免登录可浏览插件

使用方法：
将这个ZhihuCSDN.zip解压到一个固定的文件夹不要删除，浏览器打开开发者模式，点击解压缩的拓展，选择刚刚解压好的文件即可使用。
